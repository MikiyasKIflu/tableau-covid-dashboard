# 🌍 COVID-19 Global Impact Dashboard (Tableau)

## 📋 Project Overview
This project features an interactive **Tableau Public Dashboard** analyzing global COVID-19 trends, case distributions, death tolls, and population infection rates across different continents and countries.

## 🔍 Key Insights & Visualizations
* **Global KPI Summary:** High-level metrics tracking total confirmed cases, total deaths, and overall global death percentage.
* **Geospatial Analysis:** An interactive world map visualizing the percentage of the population infected per country using dynamic color scaling.
* **Continent Breakdown:** Bar charts mapping total death counts across major regions (Europe, North America, South America, Africa, Oceania).
* **Infection Trajectory:** Line charts tracking the progression of infection rates over time across key countries.

---

## 🛠️ Tools & Skills Demonstrated
* **Tool:** Tableau Public / Tableau Desktop
* **Data Visualizations:** Custom map layers, dual-axis trends, KPI scorecard blocks, and sorted bar charts.
* **Dashboard Design:** Structuring an executive layout for readability, interactive filtering, and tooltips.
